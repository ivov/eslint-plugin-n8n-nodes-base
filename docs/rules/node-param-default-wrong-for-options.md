# node-param-default-wrong-for-options

`default` for an options-type node parameter must be one of the options.

📋 This rule is part of the `plugin:n8n-nodes-base/nodes` config.

🔧 Run ESLint with `--fix` option to autofix the issue flagged by this rule.

## Examples

❌ Example of **incorrect** code:

```js
const test = {
	displayName: "Test",
	name: "test",
	type: "options",
	options: [
		{
			name: "Minus One",
			value: -1,
		},
		{
			name: "Zero",
			value: 0,
		},
		{
			name: "One",
			value: 1,
		},
	],
	default: "",
};

const test = {
	displayName: "Test",
	name: "test",
	type: "options",
	default: "wrong",
	options: [
		{
			name: "First",
			value: "first",
		},
		{
			name: "Second",
			value: "second",
		},
	],
};

const test = {
	displayName: "Test",
	name: "test",
	type: "options",
	default: "wrong",
};
```
